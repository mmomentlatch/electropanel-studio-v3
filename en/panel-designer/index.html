Components and mounting space

The library includes incoming and final-circuit breakers, RCCBs, RCBOs, voltage relays, SPDs, contactors, power supplies and control devices. Inserting a component shifts neighbouring devices according to their widths and available space.

Switch between aligned image heights and documented physical dimensions. Module capacity checks do not replace verification of the actual device series, terminals, mounting and usable depth.

Terminal-to-terminal wiring

Connect devices to other components and consumers. Set the potential, colour, material and cross-section, then edit the route. Selecting a device highlights its wires and connected equipment.

Templates contain initial ratings and assumed loads. Check cable ampacities, short-circuit conditions and outstanding issues before reviewing the design.

Getting started

  1. Choose a panel template or an empty project.
  2. Add components, rooms and electrical points.
  3. Check loads, routes and technical inputs.
  4. Review issues and export documentation.

Frequently asked questions

What can I create in ElectroPanel Studio?

DIN-rail panel layouts, terminal connections, room plans with electrical points, single-line diagrams, bills of materials and cable schedules.

Do I need to register or install software?

The current browser version requires no registration. Open the editor and start a project. After the first load, the main tools are available offline.

Where are my projects stored?

Locally in the browser on this device. Export JSON for backups and transfers. Clearing browser data can remove local projects.

Which languages and engineering profiles are available?

The interface is available in Ukrainian, English and Russian. The editor initially uses your browser preferences and remembers a manual selection. The engineering profile remains Ukrainian in every language.

Are automatically calculated lengths final?

They are preliminary quantities based on geometry, heights, routes and allowances. Verify measurements and actual installation routes on site.

Can a template be installed immediately?

A template is an editable starting layout. Installation requires actual inputs, protection and cable checks, applicable compliance review and necessary tests. Automatic installation approval is not provided.
