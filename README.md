# ElectroPanel Studio

Browser-based electrical panel and home wiring designer.

- [Українська](https://mmomentlatch.github.io/electropanel-studio-v3/uk/)
- [English](https://mmomentlatch.github.io/electropanel-studio-v3/en/)
- [Русский](https://mmomentlatch.github.io/electropanel-studio-v3/ru/)
- [Open the editor](https://mmomentlatch.github.io/electropanel-studio-v3/)

Arrange DIN-rail devices and N/PE busbars, connect terminals, draw room wiring plans, review single-line diagrams, and export bills of materials and cable schedules.

The engineering profile is Ukrainian in every interface language. Templates and calculations are preliminary; project inputs and the actual installation require engineering verification.

Projects are stored in your browser. Export JSON for backups or moving to another device. This repository contains the portable public browser distribution, including offline language bundles and vendor license notices.
